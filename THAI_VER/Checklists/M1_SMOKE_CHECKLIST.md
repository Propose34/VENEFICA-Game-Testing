# เช็กลิสต์ทดสอบความพร้อมเกมเพลย์ (Playtest Smoke Checklist) — Milestone M1

เช็กลิสต์ทดสอบ 20 ข้อ สำหรับทีมทดสอบ QA ใช้ตรวจเช็กความพร้อมอย่างรวดเร็วทุกครั้งที่เปิดเล่นหรืออัปเดตตัวเกม

| ลำดับ | สิ่งที่ต้องทำ / สถานการณ์ที่ทดสอบ | ผลลัพธ์ที่ถูกต้อง | ผลการตรวจ | หมายเหตุ |
|:---:|---|---|:---:|---|
| **01** | กดปุ่ม Play เข้าเกม | ตัวละครเกิดในร้านอย่างปลอดภัย กล้องมองเห็นตัวละครชัดเจน | [x] PASS | มุมกล้องปลอดภัยไม่ติดป้าย |
| **02** | ลองกดปุ่ม `W`, `A`, `S`, `D` | ตัวละครเดินตามทิศทางที่กล้องหันไปอย่างราบรื่น | [x] PASS | การเดินตอบสนองดี |
| **03** | กด `Left Shift` ค้างไว้ขณะเดิน | ตัวละครวิ่งเร็วขึ้นอย่างชัดเจน และชะลอลงเมื่อปล่อย | [x] PASS | ความเร็ววิ่งถูกต้อง |
| **04** | เดินชนผนังกำแพงในร้าน | ตัวละครไม่เดินทะลุกำแพง มีการชนตามปกติ | [x] PASS | ชนกำแพงทึบถูกต้อง |
| **05** | หมุนเมาส์ดันกล้องชนกำแพง/เพดาน | กล้องซูมเข้ามาใกล้ตัวละคร ไม่ออกไปเห็นที่ว่างนอกฉาก | [x] PASS | ระบบดันกล้องทำงาน |
| **06** | เดินออกประตูหลังไปที่สวน | เดินผ่านประตูได้สะดวก ไม่ติดขอบหรือกำแพงล่องหน | [x] PASS | เส้นทางเปิดโล่ง |
| **07** | เดินเข้าใกล้ต้น Moonleaf ในสวน | มีข้อความ `[E] Moonleaf` ขึ้นมา | [x] PASS | ระยะตรวจจับถูกต้อง |
| **08** | กด `E` แล้วเลือก "Leave it growing" | ต้นไม้ยังคงอยู่ในสวนเหมือนเดิม และในกระเป๋าไม่มีของเพิ่ม | [x] PASS | สถานะคงเดิม |
| **09** | กด `E` แล้วเลือก "Collect" | ได้รับ Moonleaf 2 ชิ้น และต้นไม้เปลี่ยนเป็นสถานะเก็บแล้ว | [x] PASS | ได้ไอเทมถูกต้อง |
| **10** | พยายามกดเก็บต้นเดิมซ้ำ | ไม่สามารถเก็บได้อีก ไม่ได้รับของซ้ำ | [x] PASS | ป้องกันการปั๊มของผ่าน |
| **11** | เดินผ่านทางหินและซุ้มประตูเข้าป่า | เดินได้คล่องตัว ไม่มีสิ่งกีดขวางทางเดิน | [x] PASS | เส้นทางเดินสะดวก |
| **12** | เก็บต้น Moonleaf ในป่า | ได้รับ Moonleaf เพิ่มอีก 2 ชิ้น รวมในกระเป๋าเป็น 4 ชิ้น | [x] PASS | รวมยอดถูกต้อง (4 ชิ้น) |
| **13** | เดินกลับมาหน้าเคาน์เตอร์ร้านหา Lina | มีข้อความ `[E] Talk` ขึ้นมาข้ามเคาน์เตอร์ | [x] PASS | ปุ่มคุยตอบสนองดี |
| **14** | เดินไปหลังกำแพงนอกร้านแล้วลองคุย | ไม่มีข้อความขึ้น ไม่สามารถกดคุยทะลุกำแพงได้ | [x] PASS | ตรวจจับกำแพงสำเร็จ |
| **15** | เลือกส่งเควสต์ "Give 3 Moonleaf" ให้ Lina | เงินเพิ่มจาก 40 เป็น 50 เหรียญ และเหลือ Moonleaf 1 ชิ้น | [x] PASS | คำนวณเงินถูกต้อง |
| **16** | กดคุยกับ Lina ซ้ำทันที | ตัวเลือกส่งเควสต์หายไป ไม่สามารถรับเงินเพิ่มซ้ำได้ | [x] PASS | ป้องกันการแจกเงินซ้ำ |
| **17** | เดินไปคุยกับ Rowan ที่ตลาด | บทสนทนาเปิดขึ้น ปุ่มตัวเลข 1-4 และเมาส์เลือกตัวเลือกได้ | [x] PASS | ตัวหนังสืออ่านง่าย |
| **18** | กดปุ่ม `Esc` ขณะกำลังคุย | หน้าต่างคุยปิดลงทันที และกลับมาเดินได้ปกติ | [x] PASS | คืนการควบคุมทันที |
| **19** | กด `E` สำรวจโต๊ะปรุงยา | กล้องซูมเข้าหน้าโต๊ะ และแสดงข้อความแนะนำระบบ | [x] PASS | มุมมองโต๊ะทำงานถูกต้อง |
| **20** | กด `Tab` เปิดกระเป๋า แล้วลองกดเดิน | ตัวละครยืนนิ่งสนิท ไม่เดินขณะเปิดหน้าต่างกระเป๋า | [x] PASS | ล็อกการเดินขณะเปิดเมนู |
