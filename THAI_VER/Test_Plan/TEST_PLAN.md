# แผนการทดสอบหลัก (Master Test Plan) — VENEFICA

## 1. ข้อมูลภาพรวมเอกสาร
- **ชื่อโปรเจกต์:** VENEFICA
- **ไมล์สโตน / เวอร์ชัน:** M1 First Playable Prototype (เกมแนว Cozy Gothic Witchcraft Adventure)
- **เครื่องมือพัฒนา / แพลตฟอร์ม:** Unity (URP) / PC Windows (คีย์บอร์ด & เมาส์)
- **เวอร์ชันเอกสาร:** 1.0.0
- **ผู้รับผิดชอบ:** ทีมตรวจสอบคุณภาพซอฟต์แวร์และเกมเพลย์ (QA Team)
- **กลยุทธ์การทดสอบ:** Functional Testing (ทดสอบการทำงานของระบบ), Smoke Testing (ทดสอบภาพรวมการเล่น), ตรวจสอบสิ่งกีดขวางในฉาก, และทดสอบความชัดเจนของหน้าจอเมนู (UI Readability)

---

## 2. วัตถุประสงค์ของการทดสอบ (Test Objectives)
เป้าหมายหลักของการทดสอบใน Milestone M1 คือการยืนยันว่า **วงจรการเล่นพื้นฐาน (Core Loop)** ของผู้เล่นทำงานได้อย่างถูกต้อง ราบรื่น และไม่มีบัคขัดขวาง ก่อนที่จะเริ่มพัฒนาฟีเจอร์ขั้นสูงในระยะถัดไป (เช่น ระบบปรุงยาเต็มรูปแบบ หรือระบบร้านค้าซื้อขายจริง)

หัวข้อหลักที่เน้นการตรวจสอบ:
1. ตัวละครสามารถเดิน วิ่ง และสำรวจฉากได้คล่องตัว ไม่ติดขอบ ไม่ตกแมป และมุมกล้องไม่มุดเข้ากำแพง
2. จุดสำรวจและคุยกับ NPC ทุกจุดในฉาก ต้องแสดงปุ่มกด `[E]` ที่ชัดเจนและตอบสนองถูกต้อง
3. หน้าต่างเมนู (กระเป๋า, บทสนทนา, จุดสำรวจ) ต้องล็อกการเดินของผู้เล่นขณะเปิดอยู่ และคืนการควบคุมได้อย่างราบรื่นเมื่อกดปิด
4. ข้อมูลในเกม (จำนวนไอเทม, เหรียญทอง, การส่งเควสต์, การป้องกันการเก็บของซ้ำ) ต้องคำนวณถูกต้องแม่นยำ

## 3. ขอบเขตการทดสอบ (Scope of Testing)

### 3.1 ระบบที่อยู่ในขอบเขตการทดสอบ (In-Scope)
| ระบบ / ฟังก์ชัน | รายละเอียดการทดสอบ |
|---|---|
| **การเคลื่อนที่ของตัวละคร** | เดินหน้า-ถอยหลังตามทิศกล้อง (WASD), กด Shift วิ่งเร็ว, แรงโน้มถ่วง และการก้าวข้ามสิ่งกีดขวางเล็กๆ |
| **มุมมองกล้องบุคคลที่สาม** | การหมุนกล้องรอบตัวละคร, ระบบป้องกันกล้องมุดทะลุกำแพงร้านค้า, และการซูมกล้องเข้าจุดสำรวจ |
| **ระบบบทสนทนา NPC** | คุยกับ Lina (เจ้าของร้าน) และ Rowan (พ่อค้าในตลาด), การเลือกตัวเลือกด้วยเมาส์และปุ่มตัวเลข 1–4 |
| **ระบบเก็บสมุนไพรในฉาก** | ต้น Moonleaf ในสวนและป่า, การเลือก "ปล่อยไว้" เทียบกับ "เก็บ", และการล็อกไม่ให้เก็บซ้ำ |
| **ระบบเควสต์และเหรียญทอง** | ส่งเควสต์ Moonleaf 3 ชิ้นให้ Lina -> ได้รับ 10 เหรียญทอง, ตรวจสอบการหักไอเทมและป้องกันการแจกเงินซ้ำ |
| **หน้าต่างกระเป๋า (Inventory)** | ปุ่มลัด `Tab` เปิด-ปิดกระเป๋า, การแสดงชื่อและจำนวนไอเทม, ฟอนต์ขยายพอดีกรอบ, และการล็อกการเดิน |
| **การสำรวจโต๊ะปรุงยา** | กล้องซูมเข้าหน้าโต๊ะปรุงยา (Alchemy Table) และการกด `Esc` เพื่อกลับมามุมมองปกติ |

### 3.2 ระบบที่อยู่นอกขอบเขต (ยังไม่พัฒนาในเวอร์ชันนี้)
- ระบบรดน้ำ/ปลูกผักเต็มรูปแบบ (แปลงดินในสวนเป็นจุดสำรวจเบื้องต้น)
- ระบบผสมส่วนผสมและต้มยาจริง (โต๊ะปรุงยายังเป็นจุดสำรวจแนะนำระบบ)
- ระบบเซฟเกมข้ามรอบ (เกมนี้จะรีเซ็ตข้อมูลเมื่อปิด Play Mode)
- ระบบแลกเปลี่ยนซื้อขายสินค้าจริงกับพ่อค้า Rowan (มีเฉพาะบทสนทนาถามทางในเวอร์ชันนี้)

## 4. แผนที่และจุดสำคัญในฉากทดสอบ (Visual Map Reference)
ฉากทดสอบต้นแบบประกอบด้วย 4 โซนหลักที่เชื่อมต่อกัน:
1. **ร้านปรุงยาและเคาน์เตอร์บริการ** (จุดเริ่มต้น)
2. **สวนสมุนไพรหลังร้าน** (แปลงดิน 6 แปลง และต้น Moonleaf)
3. **ตลาดประจำหมู่บ้าน** (ซุ้มร้านค้าของพ่อค้า Rowan)
4. **ซุ้มประตูหินโบราณและป่าทึบ** (เส้นทางเดินหิน และจุดเก็บสมุนไพรจุดที่สอง)

## 5. เกณฑ์การผ่านการทดสอบ (Exit Criteria)
- แบบทดสอบ Smoke Test ผ่าน **100%** (เดิน, วิ่ง, คุย, เก็บของ, ส่งเควสต์, เปิดกระเป๋า)
- **ไม่พบข้อผิดพลาดระดับร้ายแรง (Zero Critical Bugs)** ไม่มีอาการเกมค้าง (Crash), ตัวละครขยับไม่ได้ (Soft-lock), หรือตกฉาก
- บัคทุกตัวที่พบได้รับการบันทึกขั้นตอนการทำให้เกิด (Reproduction Steps) และประเมินระดับความสำคัญเรียบร้อย
